# User Stories
## For Patients
- As a patient, I want to hear my medication reminder aloud
- As a patient, I want to see big buttons I can easily tap
- As a patient, I want to call my caregiver with one tap
- As a patient, I want to see today's schedule clearly
## For Caregivers
- As a caregiver, I want to add medication schedules
- As a caregiver, I want to add event reminders
- As a caregiver, I want to receive alerts if patient needs help
- As a caregiver, I want to see if patient took their medication
